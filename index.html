Catatan

Simpan kesembilan berkas HTML dalam satu folder yang sama agar tautan antarhalaman berfungsi. Setiap halaman instrumen memiliki tautan kembali ke daftar ini. Pilihan berupa angka pada ECOG, KPS, serta ECOG dan Global Health Score di PiPS kini menampilkan deskriptornya. Deskriptor PPSv2 dilindungi hak cipta Victoria Hospice Society, sehingga halaman PPSv2 menyediakan panel untuk memuat tabel resmi dari dokumen berlisensi institusi.

Semua kalkulasi berjalan lokal di browser. Data pasien tidak dikirim ke internet. DOCX dibuat sebagai berkas .docx asli dan tetap dapat diedit di Microsoft Word/LibreOffice. PDF menggunakan dialog print browser dengan stylesheet Times New Roman 12 pt untuk keluaran.
